# Tips
I strongly recommend using [IntelliJ IDEA](https://www.jetbrains.com/idea/) as your IDE (Integrated Development Environment)
for anything related to Kotlin. Other IDEs or code editors, such as [VSCode](https://code.visualstudio.com/), unfortunately
feature lackluster support for Kotlin and Java, which means that you'll most likely run into frustrating errors.

If you need extra features and are a student, you can apply for Jetbrain's student developer
pack, which is completely free!
