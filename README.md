<h1 align="center">Tiramisu</h1>

Tiramisu is a lightweight Kotlin Library for receiving and handling Discord Interactions on either 
[JDA](https://github.com/discord-jda/JDA) or [Kord](https://github.com/kordlib/kord). F

# Philosophy
Tiramisu is as barebones as it gets when it comes to libraries. While it does provide a straightforward path towards
making interactions, it leaves the rest of the decisions to the developers. The point is to do it your way, and not have
constraints forced upon you.
